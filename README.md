## ⏱️ Cronómetro Regresivo

Aplicación web que permite configurar y controlar una cuenta regresiva mediante una interfaz sencilla y adaptable.

**Funcionalidades principales:**
- Configuración del tiempo.
- Iniciar, pausar y reiniciar el contador.
- Registro de marcas de tiempo.
- Modo de presentación y pantalla completa.
- Diseño adaptable a diferentes dispositivos.

**Tecnologías:** HTML, CSS y JavaScript.

Link: [Ver repositorio](https://github.com/Mangelcrak/Cronometro-regresivo)
